# Protocol files

`validation.mjs` implements the bounded schema subset. `public-summary.json` is a complete capability descriptor. `envelope-example.json` illustrates the command adapter stdin contract. The canonical wire contract and state/error rules are in [docs/protocol.md](../docs/protocol.md).

The sample capability is a deterministic public-text excerpt demonstration. It is not a default mandatory business capability or model-backed summary promise.
