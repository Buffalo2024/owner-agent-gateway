# Repository instructions

This is a standalone open-source project. Keep its core independent of private assistants, platform accounts, deployments, named reception agents, payment providers and mini-programs.

Read README and SECURITY before changing execution or permission behavior. Preserve caller/owner isolation, lease fencing, fixed executable selection and metadata-only logs. Use synthetic data and never import credentials or production state. New host adapters must state actual tested support and isolation limitations. Run `npm run check`, `npm test` and `npm run demo` for relevant core changes.

Do not publish, push, create remote repositories or deploy services without user authorization. No subagent delegation is required by these instructions.
