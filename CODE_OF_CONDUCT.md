# Community code of conduct

Be respectful, constructive and inclusive. Discuss implementation and evidence rather than attacking people. Harassment, threats, discrimination, doxxing and posting private credentials/data are unacceptable.

Maintainers may remove harmful content, restrict participation or close discussions that violate these rules. Enforcement should be proportionate and documented without exposing private reports. Request a private maintainer channel for sensitive conduct concerns; do not post personal information publicly.

This is a project-specific policy, not a verbatim copy of an external code of conduct.
