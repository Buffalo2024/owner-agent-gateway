# Agent Dispatch

把已有的个人 AI 助理接入标准任务协议，使其成为由主人控制、可被外部系统调度的执行端。

[English](README.md) · [快速开始](docs/quickstart.md) · [协议](docs/protocol.md) · [安全边界](SECURITY.md)

**独立项目、独立仓库维护，不要求接入指定平台或模型。**

> **先了解上下文限制：** 插件调用 dots 时，前端不显示上下文，但底层上下文实际存在。当前接入方式无法建立可验证的租户隔离与独立上下文。任务记录分开不等于助理记忆分开；不要接入互不信任的用户或敏感任务。

项目重点是已有助理的接入，而非重新开发一个助理。主人声明对外开放的能力，网关连接调度器、领取任务、启动执行并回传结果。主人保留运行环境、权限配置以及暂停和撤销接入的决定权。

**当前为实验性 v0.1.0 参考实现。** 演示采用确定性文本摘录，不调用真实模型。命令行适配器可运行，但独立进程不等于隐私沙箱。尚未提供已认证的商业助理宿主适配器，不能把演示成功理解为任意私人助理已安全接入。

## 当前定位与验证范围

个人 AI 助理能力开放协议，以及让已有助理接受外部任务的参考实现。当前适合个人开发者、受控小规模试用和单租户服务，不宣称商业级调度平台。

### 原始 dots 案例（历史真实验证）

以下真实场景结论由项目维护者完成验证并确认，不是本仓库 CI 重跑真实支付或 dots 得出的结论。

- ✅ 个人助理真实授权、领取及回写任务。
- ✅ 通过主人电脑桥接，真实事件唤醒与异步执行。
- ✅ 任务生命周期与标准 Agent 握手。
- ✅ 微信小程序真实付费到记录的完整闭环已验证：付费、需求确认、执行、成果交付、用户验收与史官记录。

**小程序链路经过主人电脑及其本地网络代理，不是公网服务器直接到 GPT 的完整转发执行。** 电脑需要保持运行和联网。详见 [真实部署说明](docs/dots-computer-bridge.zh-CN.md) 和 [脱敏源码参考](examples/dots-adapter/README.md)。

### 本开源仓库

- ✅ 独立参考调度器、网关、命令行与模拟执行器、协议测试。
- ❌ 多租户私人上下文和工具隔离，需要助理宿主及运行环境支持。
- ❌ 生产级存储：通用调度器当前为单进程 JSON；原案例的 PostgreSQL 桥接状态也不是已验证的规模化队列。
- ❌ 通用可独立安装的 dots 宿主适配器尚未完成；目录内是真实代码的历史脱敏快照。

欢迎讨论 [Multi-tenant isolation strategies](docs/discussions/multi-tenant-isolation.md)。

## 谁适合使用

适合把自己已有的助理接入受控任务流程，或学习任务协议、主人控制和本机桥接实现。
当前 dots 接入仅适合个人或单一信任域：参与者接受其上下文与工具不具备独立隔离的事实。
不适合提供承诺用户之间数据隔离的公共多租户服务，也不适合让不可信外部任务访问含私人记忆的日常助理。

## 上下文隔离由谁解决

本项目可以验证调用者身份、任务归属、租约和结果格式，但无法据此证明 dots 内部记忆隔离。
提示词要求“不读取私人记忆”、前端隐藏历史、单独 taskId 或独立网关进程都不能替代宿主隔离。
当前需要 dots 提供并明确保证独立会话、记忆分区和工具权限边界；外部接入层才能对接并验证这些能力。
我们不承诺只修改本仓库即可解决 dots 的内部上下文隔离。详见 [权限与隔离](docs/isolation.md)。

## 立即运行

安装 Node.js 24 或更新版本后：

```sh
npm ci
npm run demo
npm test
npm run check
```

无需模型密钥。演示使用真实本地 HTTP 服务完成注册、提交、领取、执行、交付，并验证暂停、恢复和撤销；临时凭证与数据在结束后清理。

## 需要为个人助理补齐什么

1. **能力契约**：输入输出结构、版本、工具和数据范围。
2. **可调用入口**：通过受支持的宿主接口启动任务。
3. **任务上下文**：仅注入获准的材料和工具。
4. **执行生命周期**：领取、心跳、超时、失败与取消。
5. **可靠结果**：结构化成果、重复请求去重、迟到结果拒绝。
6. **主人控制**：接单策略、暂停、恢复和永久撤销。

目前代码已提供通用任务协议、参考调度器、主动出站网关、命令行适配器、模拟适配器和可选插件。宿主内部的工具与私人记忆隔离需要由适配器及运行环境落实。

## 独立与可选

- 核心不依赖原平台、小程序、支付或指定模型，无需原平台账号、授权或私有代码即可运行根目录演示。
- `plugins/reception` 是可注入接待与确认逻辑的通用可选钩子，无专用服务地址。
- `plugins/miniapp` 是可选微信请求适配层；完整小程序、登录和逐用户凭证签发需宿主应用提供。
- 不包含私人助理上下文、生产数据库、密钥、用户资料或原项目的服务器配置。

## 当前限制

单进程 JSON 存储适合演示和受控试用，不能多进程共享，尚无生产负载验证。当前凭证是按角色与主体绑定的静态令牌，未实现 OAuth、自助注册或自动续期。任务自动重试仅针对租约丢失；明确报告的执行失败直接终止。网关每次处理一个任务。输入输出以小型 JSON 为主，不包含文件存储或流式交付。
